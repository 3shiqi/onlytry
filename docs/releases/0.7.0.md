# Release 0.7.0

Date: 2026-05-06

## Summary

Introduced the native iOS app scaffold with SwiftUI, SwiftData, and a medical-grade exercise-library model.

## Included

- `ExerciseModel.swift` with the V4 exercise model
- SwiftData persistence for exercises and session logs
- seed data with detailed rehab/training metadata
- `Session` tab that reads from the local database and generates today's workout
- `Library` tab that browses exercises and adds new professionally tagged exercises
- `Calendar` tab that shows logged native training sessions
- native feature and handover docs for future iOS changes

## Behavioral Notes

- native iOS now requires iOS `17.0` because SwiftData is the persistence layer
- open `ios/App/App.xcodeproj` for native development
- the web app remains available under `src/` and is still used for Cloudflare Pages
- native app display name is `Onlytry`
- native bundle ID is `com.sunshiqi.onlytry`
- native marketing version is aligned to `0.7.0`
- native target no longer packages stale Capacitor bridge resources
